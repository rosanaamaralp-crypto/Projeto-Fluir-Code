# PRIMEIRO PROMPT — ANÁLISE INICIAL DO PROJETO

Use este prompt no Replit Agent **depois** de colocar esta pasta em `/docs`.

```text
Você será o agente responsável pelo desenvolvimento do sistema Fluir da Vida.

A documentação oficial do projeto está na pasta /docs.

Antes de escrever qualquer código, leia e analise a documentação oficial.
Comece pelo arquivo 00-INDICE-E-HIERARQUIA-DOS-DOCUMENTOS.md e depois leia os documentos relevantes, dando atenção especial aos Documentos 18, 17, 16, 15, 14 e 13.

Objetivo desta primeira etapa:

1. entender o produto e suas regras de negócio;
2. identificar a arquitetura técnica adequada para o Replit;
3. identificar a stack recomendada;
4. propor a estrutura inicial do projeto;
5. identificar a estratégia de banco de dados;
6. identificar a estratégia de autenticação e autorização;
7. identificar a estratégia de testes;
8. identificar conflitos, duplicidades ou informações insuficientes na documentação.

REGRAS IMPORTANTES:

- NÃO implemente funcionalidades ainda.
- NÃO crie telas ainda.
- NÃO altere regras de negócio.
- NÃO invente requisitos.
- NÃO escolha silenciosamente entre documentos conflitantes.
- NÃO implemente o backlog futuro nesta etapa.
- NÃO faça deploy.
- NÃO avance para a próxima fase sem aprovação.

Ao final, apresente um relatório contendo:

1. entendimento resumido do sistema;
2. stack recomendada e justificativa;
3. arquitetura proposta;
4. estrutura de pastas proposta;
5. banco de dados proposto;
6. autenticação e autorização;
7. estratégia de testes;
8. riscos técnicos;
9. conflitos ou duplicidades encontrados;
10. dúvidas que realmente impedem a implementação.

Não escreva código nesta etapa.
Aguarde aprovação antes de implementar qualquer coisa.
```
