# AUTHDOC F21 — RESPONSIVIDADE GLOBAL DO APLICATIVO

## FLUIR DA VIDA OFICIAL

### OBJETIVO

Executar uma única fase concentrada para deixar TODA a interface do Fluir da Vida Oficial adequada para:

- celular;
- tablet;
- notebook;
- desktop.

A responsividade deve funcionar para os três perfis:

- ADMIN;
- PROFESSIONAL;
- CLIENT.

Esta fase é exclusivamente de FRONTEND/UI/RESPONSIVIDADE.

Não alterar regras de negócio, APIs, banco, autenticação, RBAC, ownership ou lógica de agendamento.

# 12. TABELAS E LISTAGENS

Não substituir tabelas por novos componentes sem necessidade.

Preferir:

- container com overflow-x-auto;
- colunas essenciais;
- ações acessíveis;
- largura mínima controlada;
- quebra de conteúdo onde for segura.

Quando uma lista já possui layout em cards, adaptar o card.

---

# 13. ORIENTAÇÃO PARA IMPLEMENTAÇÃO

Para economizar tempo e créditos:

1. corrigir primeiro componentes compartilhados;
2. reaproveitar classes/padrões responsivos existentes;
3. usar breakpoints já existentes no projeto;
4. evitar criar dezenas de componentes novos;
5. evitar dependências novas;
6. evitar refatorações;
7. alterar somente arquivos realmente necessários;
8. não modificar backend.

Se um problema puder ser resolvido em um componente compartilhado, preferir essa solução em vez de corrigir dezenas de páginas individualmente.
